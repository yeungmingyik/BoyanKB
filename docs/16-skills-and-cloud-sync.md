## 1. 一个技能入口，按角色使用和管理

工具箱只保留原生“技能管理”入口。五项业务场景和四种文件格式与其他技能共用原生目录，不另建业务技能列表、不迁移技能数据。

## 3. 云端负责自动同步，本机保持暂停

已启用的同步策略如下，实际运行结果见第 4 节：

| 配置 | 值与作用 |
| --- | --- |
| 执行环境 | 腾讯云 `boyankb-tencent` |
| 数据源 | `c32b43f4-41b3-4060-9820-9371bdafed8b` |
| 飞书目标空间 | `7610776951925509072`，合作伙伴专用空间 |
| 启用状态 | `active` |
| 执行频率 | 每 30 分钟一次，表达式 `0 */30 * * * *` |
| 同步方式 | `incremental`，检查新增和修改 |
| 修改处理 | `overwrite`，用飞书最新内容更新本地副本 |
| 自动删除 | `sync_deletions=false`，保持关闭 |

这是轮询式增量同步，不是飞书事件推送。每轮检查配置空间中应用可见的目录，以来源编辑时间及已保存游标识别新增和修改；变化内容导出后重新解析、分块并更新检索索引。队列等待和解析耗时会增加实际可检索时间，不能把“每 30 分钟触发”视为全部内容在 30 分钟内完成的保证。

云端脚本固定核对总部数据源、知识库及唯一目标飞书空间，保留凭据与配置内容不变，通过原生更新 API 启用定时任务。目标之外的空间不会被加入本数据源同步范围；这不等于证明飞书应用身份在所有其他位置都没有访问权限。

源端以后删除业务文档时，本地副本仍会保留。此次测试文档是在用户明确要求后单独清理，**不表示自动删除策略已开启**。需要撤回某篇业务资料时，应同时检查本地知识库并移除其副本；如以后改为自动删除，应单独评估源端权限变化被误判为删除的情况。

### 启用、检查与暂停

在目标云服务器 `/opt/boyankb` 中执行。脚本在进程内使用已有管理员凭据，不需要把密钥写入命令行。

```sh
cd /opt/boyankb
python3 scripts/tencent-feishu-schedule.py enable
python3 scripts/tencent-feishu-schedule.py enable --apply
```

不带 `--apply` 时输出计划；重复应用相同配置不重复创建任务。脚本先备份原配置，核对唯一数据源及没有正在执行的同步，再更新状态和定时计划。校验失败时尝试暂停该数据源，并明确报告暂停是否成功。运行报告为 `/opt/boyankb/feishu-schedule-report.json`。

暂停后续自动触发：

```sh
cd /opt/boyankb
python3 scripts/tencent-feishu-schedule.py pause
python3 scripts/tencent-feishu-schedule.py pause --apply
```

暂停不等于取消已入队任务。执行后仍应检查同步日志及队列，确认没有正在执行、待执行或重试任务。暂停操作保留既有定时表达式，数据源状态为 `paused` 时调度器不会继续登记该任务。
