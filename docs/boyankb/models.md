# 模型服务

## 使用模式

| 模式 | 密钥与费用 | 实现 |
|---|---|---|
| 伙伴自购 | 伙伴向供应商购买、保存自己的密钥 | LibreChat 原生个人 API Key，配置 `user_provided` |
| 公司提供 | 公司发放伙伴专属的网关访问密钥与额度 | 原生兼容端点；网关负责配额、停用和计量 |
| 本地模型 | 使用管理员允许的本地服务 | 单独配置兼容端点及访问范围 |

公司主密钥不下发到浏览器或伙伴账号。不把一个服务端公司密钥默认为全部 USER 免费可用。公司网关供应商和价格待选定，实际购买、收费、自动充值与支付回调不在本地部署版本中实现。

## 供应商

保留 LibreChat 原生 OpenAI、Anthropic、Google 及自定义端点。DeepSeek 采用 OpenAI 兼容接口。其他服务商可使用原生 OpenAI/Anthropic 兼容端点，填写个人 API Key 和服务地址；不支持的私有协议需要单独适配并验收。

DeepSeek 初始配置：`https://api.deepseek.com`；模型 `deepseek-flash`、`deepseek-v4-pro`。模型列表可按实际账户更新，不能把静态默认列表当作账户可调用性证明。[DeepSeek 官方接口](https://api-docs.deepseek.com/)

自定义端点复用原生 `apiKey: user_provided`、`baseURL: user_provided`，保持原生服务端地址校验，不开放私网与本机地址绕过。管理员明确配置的本地模型另行配置允许地址。[LibreChat 端点契约](https://www.librechat.ai/docs/configuration/librechat_yaml/object_structure/custom_endpoint)

使用代理的 PC 须确认供应商域名解析为可路由公网地址。若代理使用 Fake-IP DNS，优先调整 DNS 模式；确需保留时，由管理员在私有配置的 `endpoints.allowedAddresses` 中逐个填写已核实的供应商域名与端口，例如 `api.deepseek.com:443`。不添加整个保留地址段、通配域名或未知内网服务。

个人密钥对话框支持填写模型 ID，每行一个，也可用逗号分隔。模型 ID 与个人密钥一并加密保存，只进入该用户的模型目录；原生菜单和服务端模型校验使用相同目录。不提供模型列表的兼容服务可通过该字段配置。配置中的默认模型仅为默认选项，不代表任意服务商均支持。

## 授权与密钥

进入模型选择、个人密钥、聊天与资料入口前，检查本地登录和知识 Agent VIEW。原生密钥接口只能操作当前登录用户的密钥，不能通过 body 或 URL 指定另一个用户。

个人密钥以原生加密存储方式保存，读取接口只返回配置状态和到期信息。请求日志、错误、评测报告、截图和 Git 不记录实际密钥。撤销知识权限同时停止该用户后续模型请求，不删除其供应商账户。

自购密钥请求失败时直接返回该供应商的可操作错误，不自动回退到公司密钥。公司网关额度用尽或密钥停用时同样不绕过计费。公司服务的授权和知识授权需同时有效。

## 知识检索

问答模型由用户选择；embedding 模型由管理员统一配置。更换问答供应商不重建共享索引，更换 embedding 模型须重建并切换索引版本。

alpha.2 提供原生多供应商选择和账号授权。alpha.4 在服务端完成检索、资料过滤和引用映射，再调用选定供应商。不把仅能普通聊天的开发版本标记为已支持知识问答。

## 验收

- A、B 两个用户保存不同测试密钥；读取、删除、调用均不跨用户，数据库和响应不出现明文密钥。
- DeepSeek 及另一种供应商或兼容端点各完成一次授权调用；真实服务测试使用用户提供的密钥，未提供时仅记录适配和隔离测试。
- 更换模型后，知识范围、下线过滤、原文引用和用户私有会话保持一致。
- 未授权、撤权、封禁状态均不能利用模型端点、原生个人密钥或平台 API Key 绕过门禁。
- 自定义服务地址不能访问不允许的私网或本机资源；测试使用隔离目标。
- 公司服务按专属网关密钥隔离额度，停用后调用拒绝；不使用公共公司主密钥替代授权。
