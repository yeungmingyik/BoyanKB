# BoyanKB 验收清单

当前验收版本：`0.1.0-beta.1` 伙伴试点版。正式 HTTPS 入口、最终镜像移动端 7 组、公网浏览器 6 组、会话与权限检查通过；10 人并发的 130 次性能请求全部成功。各项结果对应的镜像与环境见第 10 节。正式应用、Worker 与隧道健康，升级前后资料版本和索引关联一致。实际覆盖为 18 份资料、12 份发布、6 份未发布；真实企业题集、完整格式、公司网关、PC 重启与备份恢复演练尚未通过。

## 1. 验收条件

- 使用明确的应用提交、产品版本和部署配置。
- 准备管理员、员工、两名合作伙伴用户、已登录但无知识 Agent `VIEW` 的用户及未登录会话。
- 知识 Agent 由管理员持有，仅通过原生分享界面逐用户授予 `VIEW`，不配置角色级 `VIEW`。
- 使用脱敏样例覆盖业务资料、重复版本、删除、目录移动、缺失信息、冲突资料和嵌入对象。
- 真实知识空间的核对材料保存在私有运行环境，不提交公开仓库。
- 记录实际运行设备、模型、知识版本、执行日期、结果和缺陷；未执行项不能标记通过。
- 仅运行与改动相关的自动化与人工检查；发布前完成该版本对应的验收集合。

## 6. 发布门槛

beta.1 的本地并发门槛为 10 名独立授权用户：阅读 P95 ≤ 3 秒、关键词检索 ≤ 5 秒、语义检索 ≤ 8 秒、问答从请求到完整核验结果 ≤ 15 秒，各类请求错误率为 0。阅读与检索各 3 轮，问答每人 1 次；同时验证未授权拒绝与会话隔离。模型替身与真实供应商分别记录，冷启动和后续请求均须验证。公网耗时另行记录，不以本机结果替代目标网络验收。

- `0.1.0-alpha.2`：AC-01 至 AC-07、AC-31、AC-32、AC-35，通过已存在的接口范围；后续新增接口须补验 AC-01、AC-04、AC-06、AC-31、AC-32。
- `0.1.0-alpha.3`：AC-08 至 AC-16、AC-18、AC-34；实际格式缺口保留清单，不宣称全空间已全部可用。
- `0.1.0-alpha.4`：AC-19 至 AC-24、AC-33、AC-36，通过问答验收集，并补验新增接口的权限、撤权和资料删除联动。
- `0.1.0-beta.1`：AC-25、AC-26、AC-30；10 人并发、伙伴实际使用范围与资料覆盖状态明确。AC-37 公司网关、真实企业题集和 6 份资料缺口暂缓。
- `0.1.0`：AC-01 至 AC-37 均有通过记录，实际资料格式覆盖完成，无未解决的越权、资料丢失或错误发布缺陷。

`0.2.0` 云迁移须重新验证目标网络、权限、数据恢复、部署配置与版本回退，并核对迁移前后数据完整性。
