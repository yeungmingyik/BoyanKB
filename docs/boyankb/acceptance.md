# BoyanKB 验收清单

当前验收版本：`0.1.0-alpha.3` 预发布版。读取与服务组件的 HTTP、RAG 与浏览器合成场景复验通过，最终镜像的 HTTP 与独立 Worker 验收通过；首次整空间发现 18 份资料，12 份已发布、6 份有明确未发布原因。最终镜像的正式部署阅读与索引核对通过，全格式可用性未通过。alpha.2 通过记录保留其原有范围，不能替代新增接口的验证。未执行项不作为已通过或已发布的证明。

## 1. 验收条件

- 使用明确的应用提交、产品版本和部署配置。
- 准备管理员、员工、两名合作伙伴用户、已登录但无知识 Agent `VIEW` 的用户及未登录会话。
- 知识 Agent 由管理员持有，仅通过原生分享界面逐用户授予 `VIEW`，不配置角色级 `VIEW`。
- 使用脱敏样例覆盖业务资料、重复版本、删除、目录移动、缺失信息、冲突资料和嵌入对象。
- 真实知识空间的核对材料保存在私有运行环境，不提交公开仓库。
- 记录实际运行设备、模型、知识版本、执行日期、结果和缺陷；未执行项不能标记通过。
- 仅运行与改动相关的自动化与人工检查；发布前完成该版本对应的验收集合。
