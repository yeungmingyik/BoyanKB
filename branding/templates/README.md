# 博研文化文件模板

版本：`boyan-v1`。平台显示 BoyanKB，正式文件使用博研文化。原始图形来自 `branding/logo.png`，颜色来自 `branding/brand.json`，没有重新描摹或改变标志比例。

| 场景 | 模板 | 设计与用途 |
| --- | --- | --- |
| 教学 | `teaching.pptx`、`teaching.docx`、`teaching.xlsx`、`teaching.md` | 浅蓝底、深蓝标题；学习目标、讲解、练习、作品记录；表格用于课程节奏与时长核对 |
| 商务 | `business.pptx`、`business.docx`、`business.xlsx`、`business.md` | 深蓝封面、白底正文；合作需求、业务范围、双方职责、待确认条款；表格用于沟通和确认 |
| 运营 | `operations.pptx`、`operations.docx`、`operations.xlsx`、`operations.md` | 青蓝重点色；任务分工、准备与执行、风险、复盘；表格用于预算测算 |

PPT 为 16:9，可编辑文本、图形和原生表格；每套六页。Word 为两页结构模板，含页眉、页脚、来源与待确认事项。Excel 保留输入区、校验及公式；预算缺失时显示“待补齐预算”，不会默认为零。Markdown 保留标题、内容和来源插槽。

## 内容依据

结构参考本机授权知识库中的《第二部分：教学核心套件（内容标准化）》《第四部分：运营管理 SOP（行为标准化）》及 `docs/business/agents-spec.md`。知识库 ID 为 `d9285ed1-0760-474b-ba82-a13347598176`。模板只承载结构，不复制内部产品手册、价格、客户案例或未经确认的课程细节。

生成时重新检索授权知识库、绑定真实文档及分块、核验内容摘要。伙伴自己上传的资料不能作为总部产品、价格、案例或承诺的依据。事实、创意建议、预算假设及待核实信息必须区分。

## 已完成的模板验证

2026-10-09，本机 Microsoft PowerPoint、Word、Excel 分别成功打开三套对应文件。PowerPoint 每套六页、Word 每套两页；逐页检查十八张幻灯片与六页 Word 输出。Excel 运营模板输入测试得到 1820 元，删除一项输入后显示“待补齐预算”。PPT 导出通过原生表格与版面检查，三张工作表无公式错误。

这些结果验证模板本身；真实 Agent 生成文件的验收另见 `docs/04-presets.md`，不能把模板通过等同于业务生成通过。

## 更新

`manifest.json` 保存每个文件的 SHA-256。更换文件必须提升模板版本、重新计算摘要，并同步预设版本和渲染器允许的版本。渲染器健康检查拒绝摘要不匹配的资源，开通脚本不会把此环境标为就绪。

先检查原生 Office 文件和实际生成结果，再重新构建文件渲染器、应用及前端镜像。保留旧版本镜像与资源用于回滚；不要在原标签下替换不同版本的模板。
